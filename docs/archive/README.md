# Archive

Superseded and deprecated documentation lives here — and only here.
Referenced by `AGENTS.md` and `docs/README.md`: archived material is never
guidance and is excluded from the decision order.

## Rules

- Move documents here **verbatim**; do not rewrite history.
- Prepend a short archival header to each moved file:

  ```
  > Archived YYYY-MM-DD from `<original/path>`.
  > Superseded by: `<replacing doc or ADR>` (or: nothing — dropped).
  ```

- Never delete archived files; corrections happen in the superseding doc.
- When a plan document is superseded by an accepted ADR, note both
  directions: the ADR lists what it superseded, the archived copy links
  forward to the ADR.
